🌱 Sustainable Food Management System

A full-stack web application designed to reduce food waste, optimize food distribution, and promote sustainability by connecting donors, organizations, and recipients.

🚀 Features
🥗 Food Donation Management
Users can donate surplus food
Add details like quantity, type, expiry
📦 Food Request System
NGOs / individuals can request available food
Real-time availability tracking
📍 Location-Based Matching
Connect donors with nearby recipients
👤 User Authentication
Secure login and registration system
This project is deployed on Render.

👉 Live Link:https://sustainable-food-management-2.onrender.com
